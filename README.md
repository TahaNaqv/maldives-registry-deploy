Maldives Blue Carbon Registry, working prototype (Ideofuzion)

Deploy to Vercel, either:
  1. Drag this folder onto https://vercel.com/new (Deploy without Git), or
  2. From a terminal inside this folder:  npx vercel --prod

Static site, no build step. index.html is the whole app; vercel.json only adds a noindex header
so the demo does not appear in search engines. Sample data lives in the visitor's browser.
